# MP2: Data Processing REST API

This project is a FastAPI application that turns the MP1 data-cleaning pipeline into a web API. `POST /upload` accepts a CSV file, stores it in memory, and returns its ID along with its row and column counts. `GET /datasets/{dataset_id}` returns up to `limit` rows of a stored dataset plus its total row count. `POST /datasets/{dataset_id}/process` takes a JSON configuration, validates the stored data, removes duplicates, missing values, and optionally outliers using the reused MP1 modules in `data_pipeline/`, saves the result, and returns a cleaning report. `GET /health` confirms the server is running. Middleware gives every request an eight-character ID, returned in the `X-Request-ID` header, and logs its method, path, status code, and duration. The `tests/` folder contains pytest tests for the upload, process, and retrieval workflow.
